# Phase 7: Mac内の音声の取り込み（将来）

## 目的

イヤホンでオンライン会議に参加しているときでも、相手の声（Macから出る音）を文字起こしできるようにする。あわせて、マイク側を「自分」、Mac内の音声側を「相手」として区別する。

このフェーズは方式の調査から始める。Phase 6 までと違い、設計時点で手順を確定できていない。

## 先に読むもの

- [AGENTS.md](../../AGENTS.md)（特に「新しいAPIの扱い」）
- [DESIGN.md](../DESIGN.md) §4.1（Audio）、§4.2（Transcription）

## 最初に確認すること

DESIGN.md §8 の #8 を公式ドキュメントとSDKで確認し、結果を表に書き込む。確認する点:

- システム音声を取り込む方法の候補（Core Audio のプロセスtap、ScreenCaptureKit の音声取得）と、それぞれに必要な権限、Info.plist のキー、entitlements
- サンドボックスを有効にしたままで使えるか
- 特定のアプリ（会議アプリ）の音声だけを取り込めるか
- `SpeechAnalyzer` を2系統（マイク用とシステム音声用）同時に動かせるか、動かした場合の負荷

調査結果と、採用する方式の案を先に報告する。実装は、その案が了承されてから始める。

## 作業内容（調査結果に応じて見直す）

1. `Audio/`: `AudioSource` を実装するシステム音声用のソース
2. 2系統の文字起こし
   - マイクとシステム音声を別々に文字起こしし、`TranscriptSegment` に話者の区分（自分 / 相手）を持たせる
   - 2系統のセグメントを時刻順に並べて表示する
3. 重複への対処
   - スピーカーから音を出している場合、相手の声をマイクも拾い、同じ発言が2回文字になる。イヤホン利用時だけシステム音声の取り込みを有効にする、などの方針を決める
4. ライブ更新と議事録への反映
   - Luna と Sol への入力に話者の区分を含め、システムプロンプトにその説明を足す
5. 設定と画面
   - システム音声の取り込みのオン / オフ
   - 文字起こしに話者の区分を表示する
6. テスト
   - 2系統のセグメントの並べ替え
   - 話者の区分つきの入力JSON

## 範囲外

- 3人以上の話者の識別

## 受け入れ条件

- ビルドとテストが通る
- システム音声の取り込みをオフにした場合、Phase 6 までと同じ動作になる
- DESIGN.md が、採用した方式に合わせて更新されている

## 人が確認する項目

- イヤホンを使ったオンライン会議で、相手の声が「相手」として文字になる
- 自分の声が「自分」として文字になり、相手の発言と時刻順に並ぶ
- 同じ発言が2回文字にならない
- 権限を拒否した場合でも、マイクだけで動く
