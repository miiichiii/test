# Phase 4C: マイクの選択

## 目的

このアプリで使うマイクを、設定画面で選べるようにする。既定は今までどおり「Mac の設定に従う」。

Phase 4B の後に、利用者の求めで追加したフェーズ。番号は順序を表すだけ。

- [AGENTS.md](../../AGENTS.md)
- [DESIGN.md](../DESIGN.md) §4.1（Audio。特に「マイクの選択」）、§4.8（Settings）、§5（画面）

## 最初に確認すること

- Core Audio のデバイス一覧の API と、`AUAudioUnit.setDeviceID(_:error:)` を SDK のヘッダで確かめる
- DESIGN.md §8 の #13 は実機でしか確かめられないので、人による確認の項目に入れる

## 作業内容

1. `Audio/`
   - `AudioInputDevice`（UID と名前）と、入力を持つデバイスの一覧、UID からデバイスを探す処理、一覧の変化の通知
   - `MicrophoneSource`: 選ばれた UID を受け取り、エンジンを作るたびに入力デバイスを設定する。見つからなければ Mac の設定のマイクで録音し、一覧が変わったら選んだマイクに戻す。録音中に選び直したら、すぐに切り替える
2. `Settings/`: `AppSettings` にマイクの UID と名前
3. 画面: 設定画面の「文字起こし」の節に「マイク」の選択欄
4. テスト（実際のマイクには触らない）
   - 選ばれた UID からデバイスを決める処理（見つかる・見つからない・未選択）
   - 設定の保存と読み込み
   - 一覧の取得が落ちないこと（中身は機材によるので、形だけを確かめる。装置が0個の環境でも通る）
   - 「選ばれた UID、一覧、今使っているマイク」から「作り直すか」を決める処理（同じなら何もしない）
   - 選択欄の項目の組み立て（既定・一覧・未接続の行、既定の名前がない場合）
   - 一覧の変化の通知を作ってすぐ捨てても落ちないこと
   - 作り直しの回数の上限

## 範囲外

- 複数のマイクを同時に使うこと
- Mac 内の音声の取り込み（Phase 7）

## 受け入れ条件

- ビルドとテストが通る
- マイクを選ばない場合（既定）の動作が、今までと変わらない

## 人が確認する項目

- 設定画面の「マイク」に、つないでいるマイクが並ぶ。抜き差しすると一覧が変わる
- 内蔵マイク以外（AirPods、USB マイクなど）を選んで会議をすると、そのマイクの声が文字になる（入力レベルのメーターも動く）
- 録音中に選び直すと、すぐにそのマイクに切り替わる
- 選んだマイクを録音中に抜くと、Mac の設定のマイクで録音が続く。つなぎ直すと、選んだマイクに戻る
- 選んだマイクがつながっていないまま起動すると「（未接続）名前」と出て、Mac の設定のマイクで録音される
- 「Mac の設定に従う」に戻すと、今までどおり動く
- 別のマイクを選んで録音している間も、音楽などの再生は元の出力のまま続く（AirPods をマイクにしたときの音質の低下は除く）
- マイクを選んだ状態でシステム設定の入力を変えても、使うマイクは変わらない。「Mac の設定に従う」なら追従し、括弧の中の名前も変わる
- 録音していないときに選び直しても、マイクのインジケータ（メニューバーのオレンジの点）が点かない
- 選んだマイクを抜いた後、数秒以内にメーターが動き、文字起こしが続く（無音で固まらない）
- コンソール.app で「録音を再開した」のログが続けて出続けない（作り直しがループしていない）
- AirPods と USB マイク（48kHz など）の両方で文字になる
- 一時停止と再開をまたいでも、選んだマイクのまま
- BlackHole などの仮想デバイスを選んでも落ちない
- マイクの許可の前に設定画面を開いても、一覧が出る
